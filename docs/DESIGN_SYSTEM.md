# Zebri Design System Direction

> **Brand Reference:** All design decisions must align with `.claude/brand-guide.md`. When in doubt, the brand guide is the source of truth for colors, typography, logo usage, and tone.

Inspired by Notion: minimal, light, professional, no-nonsense.

## Color System (sourced from brand guide)

- Background: #FFFFFF (pure white)
- Primary text: #111827 (near-black)
- Secondary text: #6B7280 (medium gray)
- Muted: #9CA3AF (metadata, captions)
- Borders: #E5E7EB (very light gray)
- Accent: **#A7F3D0 (Mint Green)** — highlights, active states, chart lines, toggles
- CTA buttons: #111111 (black) — the only dominant dark color
- Card bg: #FAFAFA (off-white for subtle section cards)

### Color Rules (from brand guide)
- Never use more than 2 brand colors in a single composition
- Black and white dominate — mint is an accent only
- Use mint for small highlights, NOT large fills or backgrounds
- No gradients
- No blue accent (#3B82F6 is explicitly removed in favour of mint)

## Characteristics

- Notion-like minimalism (not heavy design)
- Generous whitespace
- Soft borders (1px, light gray)
- NO rounded corners—use 4px-6px max (Notion style)
- Light neutral backgrounds
- High-contrast typography
- Subtle hover transitions only

## Typography

- Display: Inter (bold, 600-700 weight for headlines)
- Body: Inter (400-500 weight, 16px base)
- Large spacing between sections (80px+ on desktop)

## Do NOT

- Use dark backgrounds or near-black
- Overuse color
- Use heavy gradients
- Use stock photography
- Use cheesy wedding imagery
- Animate excessively

This is professional SaaS, not a wedding site.
